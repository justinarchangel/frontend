# Mockups

What a page should look like, before anyone builds it. One file per page, named for the page:
`feed.html`, `feed.png`, `company.png`. Make it any way you like: ask your agent for a static
HTML page, use a chat's canvas, use a design tool, or draw it on paper and add a photo.

When you've picked one, point your agent at it: "Build the feed to match
`mockups/feed.png`." Then put the page and the mockup side by side, at full width and at a
phone's width, and judge how close it got.
