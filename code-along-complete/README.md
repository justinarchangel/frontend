# Finished code-alongs

Each folder is one code-along as it ended in class. The files inside sit at the same paths
they have in the app, so you can open yours and the finished one side by side, or copy a file
over yours to catch up. The folders don't depend on each other.

| Folder | What it finishes |
|---|---|
| `1-access/` | `users#show` turns away anyone who is not the user in the address. Before this, `/users/2` showed any user's email to anyone. |
| `2-json/` | `posts#index` also answers `/posts.json` with the posts as data, which the page at `/spa/index.html` reads. |

Nothing here for the page's look: every mockup is different, so every finished page is too.
